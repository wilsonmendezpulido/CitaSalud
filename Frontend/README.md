# Frontend – CitaSalud

## Tecnología

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP Views

## Características HCI

La interfaz fue diseñada considerando:

- Consistencia visual.
- Navegación sencilla.
- Jerarquía visual.
- Retroalimentación de acciones.
- Mensajes claros.
- Formularios estructurados.
- Diseño responsive.
- Contraste adecuado.
- Reducción de carga cognitiva.
- Prevención de errores.

## Principales vistas

- Página inicial.
- Login.
- Dashboard.
- Especialidades.
- Médicos.
- Disponibilidad.
- Confirmación de cita.
- Resultado de cita.
- Mis citas.
- Detalle de cita.
- Perfil.
- Edición de perfil.
- CRUD de pacientes.

## Navegación

El sistema utiliza una navegación consistente mediante un menú superior
que permite acceder a:

- Inicio.
- Programar cita.
- Mis citas.
- Mi perfil.
- Cerrar sesión.

## Responsive

La interfaz utiliza Bootstrap 5 para adaptar componentes y
contenedores a diferentes resoluciones de pantalla.
